Setup

← Back to class

Please do these before class so we can spend our time building, not installing. It takes about 30 minutes. If you missed it, do it now. Your cohort can help.

1 Bring your laptop, charged

2 Finish the GitHub tutorial

Finish the GitHub Skills "Introduction to GitHub" tutorial, and make sure you can sign in to github.com.

3 Install Git

Mac

Open Terminal and run:

git --version

If a prompt appears, click Install.

Windows

Open PowerShell and run:

winget install --id Git.Git -e --source winget

Then close PowerShell and open a new window.

4 Check that it worked

git --version

A version number, like git version 2.47.1.

5 Tell Git who you are

Run these two commands with your own name and the email address on your GitHub account. Git records them in every commit you make.

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

6 Install the GitHub CLI

Mac

First install Homebrew: copy the install command from brew.sh into Terminal. Enter your Mac password when asked. Nothing shows on the screen as you type, which is normal.

When it finishes, run the commands it prints under Next steps. Then run:

brew install gh

Windows

winget install --id GitHub.cli

Then close PowerShell and open a new window.

7 Sign in to GitHub from the terminal

gh auth login

Choose GitHub.com, then HTTPS, then sign in with a web browser. It gives you a one-time code to paste into the browser.

8 Check that it worked

gh auth status

That you're logged in to github.com, with your GitHub username.

9 Install Codex CLI

This is the version of Codex that runs in your terminal, so it can work directly with the files on your laptop. ChatGPT in the browser can't do that, so it isn't enough for this class.

Mac

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Windows

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Already using the Codex extension in VS Code? You can use that instead.

10 Sign in to Codex

Open a new terminal window and run:

codex

Choose Sign in with ChatGPT, and use your BYU ChatGPT account.

11 Have your AI Build Day app on your laptop

Put it in its own folder. No working app? Use the instructor's hangman game instead. On Windows, right-click the zip and choose Extract all.

Download hangman.zip
